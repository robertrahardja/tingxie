# Image Attribution — row 98 vocabulary

Row 98 returns to the in-house SVG illustration approach used by rows 92–96
(row 97 used sourced photographs). Bing image search was tried first for the
nine missing words and returned almost entirely unusable results — generic
placeholders, watermarked stock previews, and off-topic diagrams — so each
scene was instead drawn from scratch.

All nine pictures are original flat-vector scenes generated by
`scripts/draw_row98_images.py` and rendered to PNG with `rsvg-convert`.
They contain no third-party material and no text: the script asserts that
no `<text>` element is present, because the word under test must never
appear in its own picture.
